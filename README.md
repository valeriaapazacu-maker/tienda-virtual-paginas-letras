# Paginas & Letras - Tienda virtual

Aplicacion de comercio electronico con React + Vite + Tailwind + shadcn/ui (frontend) y Django REST Framework (backend).

## Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

## Frontend
cd frontend
npm install
npm run dev
